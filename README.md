# ندى — Nada

تطبيق ويب وAndroid هادئ لحفظ الريلز والصور العامة من إنستغرام، بواجهة زجاجية على طريقة الآيفون.

تطبيق الأندرويد يُبنى تلقائياً عبر GitHub Actions (`gradle :app:assembleDebug`) ويظهر الـ APK في Releases.

من إنستغرام: مشاركة → ندى، فيُجلب المنشور مباشرة.

## تنزيل الريل بضغطة واحدة (1.58)

وأنت تشاهد ريل داخل إنستغرام، اضغط الزر العائم مرة واحدة فيُنزَّل نفس الريل، بدون نسخ الرابط وبدون فتح IG SAVE.

التفعيل اختياري ومغلق افتراضياً: من «حول التطبيق» ← «تنزيل الريل بضغطة واحدة» ← فعّل **IG SAVE** في إعدادات إمكانية الوصول.
على أندرويد 13+ إذا كان المفتاح رمادياً: معلومات التطبيق ← القائمة ⋮ ← «السماح بالإعدادات المقيّدة»، ثم عد وفعّله.

الخصوصية: الخدمة مقيّدة بحزمة إنستغرام فقط، ولا تعمل إلا بعد ضغطتك على الزر. تفتح قائمة المشاركة وتضغط «نسخ الرابط» عبر وصف العنصر لا عبر إحداثيات الشاشة، ولا تقرأ النص ولا كلمات المرور ولا محتوى أي تطبيق أو شاشة أخرى، ولا تلتقط الشاشة. إن تغيّر تصميم إنستغرام تظهر رسالة «انسخ رابط الريل أولاً» فقط.

## التشغيل

```bash
cd nada
pip install -r requirements.txt
python3 -m uvicorn server:app --host 127.0.0.1 --port 8000
```

ثم افتح المتصفح على العنوان الذي يظهر.

## ماذا يفعل

- لصق رابط ريلز أو منشور أو ألبوم عام
- معاينة الملف قبل الحفظ
- تنزيل الفيديو أو الصورة بجودة إنستغرام المتاحة، بلا علامة مائية
- مكتبة محلية لآخر المنشورات التي جلبتها
- عربي / English

يعمل مع المنشورات **العامة فقط**. الحسابات الخاصة والقصص غير مدعومة.

للحفظ الشخصي. حقوق المحتوى تبقى لصاحب الحساب.
